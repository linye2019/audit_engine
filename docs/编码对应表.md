# 医保智能审核引擎 — 编码对应表

> 统一采用**中文拼音首字母缩写**命名体系，2-6 位大写字母，见名知义。

---

## 一、四柱编码（pillar）

| 编码 | 全称 | 含义 |
|------|------|------|
| **YP** | 药品 | 柱1：药品目录限制（适应症/性别/年龄/二线/疗程等） |
| **HC** | 耗材 | 柱2：耗材使用合规（配对/适应症/用量） |
| **FW** | 服务 | 柱3：项目收费合规（超标准/重复/分解收费） |
| **BZ** | 病种 | 柱4：DRG/DIP 支付合规性（高套/分解/低标） |

---

## 二、三目录表名（catalog table）

| 编码 | 原表名 | 对应柱 | 说明 |
|------|--------|-------|------|
| **YP** | drug_catalog | 柱1 | 药品目录（通用名/剂型/ATC分类） |
| **FW** | project_catalog | 柱3 | 诊疗项目目录（15位立项指南编码） |
| **HC** | unified_materials | 柱2 | 统一耗材目录（基本物耗/普通/特殊功能） |

### 关联桥表

| 表名 | 说明 |
|------|------|
| **FW_codes** | 项目↔国家编码（原 project_catalog_codes） |
| **FW_aliases** | 项目↔别名（原 project_catalog_aliases） |
| **FW_connotation** | 项目内涵（原 project_connotation） |

---

## 三、DRG 规则类型（rule_type in drg_rules）

| 编码 | 全称 | 检测逻辑 |
|------|------|---------|
| **GT** | 高套 | 合并症编码数量异常多 / 主诊断权重偏离 |
| **FJ** | 分解 | 同一患者同病种 15 天内再次住院 |
| **DB** | 低标 | 住院天数 ≤1天 且 费用低于门诊阈值 |
| **SJ** | 缩减 | 费用消耗指数远低于区域均值 |
| **ZSBP** | 诊手不配 | 主诊断与主手术无临床关联 |
| **PY** | 漂移 | 同一病种入组权重时间序列异常波动 |
| **WRZ** | 未入组 | 住院记录无 DRG 编码 |
| **DFSW** | 低死亡 | DRG 组为低风险但患者死亡 |
| **ZY** | 转院 | 转院患者费用异常 |
| **DZ** | 短住 | 住院天数短但费用高 |
| **GQZ** | 高权重 | DRG 权重高于阈值 |
| **ZF** | 自费 | 个人负担比例异常 |
| **CE** | 差额 | 总费用与 DRG 支付额差额较大 |
| **QSS** | 缺手术 | DRG 分组为手术组但无手术编码 |
| **CZ** | 长住 | 住院天数异常偏长 |
| **YCDZ** | 异常短住 | 短住 + 高费用不匹配 |

## 五、编码体系总览

```
pillar（四柱）      table（目录表）       rule_category（规则类别）   rule_type（DRG类型）
────────────────────────────────────────────────────────────────────────
YP ──────────────→ YP ─────────────→ YP_SYZ / YP_XB / ...
                                       ↑
HC ──────────────→ HC ─────────────→ HC_SP / HC_PD / ...
                                       ↑
FW ──────────────→ FW ─────────────→ FW_XMHC / FW_DJZJ / ...
                                       ↑
BZ ──────────────→ (无目录表) ─────→ (无类别) ─────────────→ GT / FJ / DB / ...
```
