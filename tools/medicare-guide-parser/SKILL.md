# 医疗服务价格项目立项指南解析器

本 Skill 专门用于解析国家医保局及各省市医保局发布的医疗服务价格项目立项指南（征求意见稿/正式稿）Excel 文件，自动识别主项、加收项、扩展项、减收项等项目类型，并以结构化方式输出解析结果。

## 适用场景

- 用户上传立项指南相关 Excel 文件（文件名含"立项指南""项目对应""拟定价格""价格拟定"等关键词）
- 用户要求解析、归纳、总结医疗服务价格项目立项指南数据
- 用户需要区分主项与分项（加收项/扩展项/减收项）
- 用户需要将立项指南数据导入数据库或生成项目清单
- 用户需要分析某类别立项指南的项目结构、价格构成、计价规则

## 文件识别

### 文件命名规律

立项指南文件通常遵循以下命名格式：

```
YYYYMMDD_【地区】XX类立项指南项目对应及拟定情况（征求意见稿）.xlsx
YYYYMMDD_【地区】XX类项拟定价格情况.xlsx
附件N_XX类立项指南对应情况及价格拟定.xlsx
XX类立项指南映射项目表.xlsx
XX类医药科测算用.xlsx
```

示例：
- `20260310_心血管系统类立项指南项目对应及拟定情况（征求意见稿）.xlsx`
- `20250930_（泉州）中医骨伤及特殊疗法拟定价格.xlsx`

### 项目类型分类体系

立项指南 Excel 中，项目代码（15位国家编码）的后4位编码后缀严格区分项目类型：

| 代码后缀（后4位） | 项目类型 | 说明 |
|-----------------|---------|------|
| `0000` | **主项** | 独立的医疗服务价格项目基准 |
| `0001/0011/0021` | **加收项** | 在主项价格基础上加收 |
| `0100/0200` | **扩展项** | 不额外加价，扩展适用范围 |
| 其他后缀 | **其他分项** | 按特定部位或方式细分 |

## 输出格式

解析完成后生成包含 4 个 Sheet 的 Excel 文件：

| Sheet | 说明 |
|-------|------|
| **全部数据** | 所有项目完整数据，保留立项指南原始核心字段 |
| **按类型汇总** | 各类型数量及占比统计表 |
| **后缀规律分析** | 展示该类别的编码后缀分布规律 |
| **主项子项对照** | 主项与子项的树形对照关系 |

## 使用方式

```bash
# 解析单个文件
python3 parse_guide.py <excel文件路径> --output <输出目录>

# 批量解析目录
python3 parse_guide.py <目录路径> --batch --output <输出目录>
```

## 与规则注册中心的关系

解析结果可映射到 `docs/RULE_REGISTRY.md` 注册中心，为规则引擎提供：
- 项目代码 → `FW.med_list_codg`
- 加收/减收条件 → `rule_items.conditions`（加收规则）
- 计价说明中的除外内容 → `rule_items.conditions`（互斥规则）
